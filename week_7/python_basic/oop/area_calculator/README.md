# מחשבון שטח והיקף לצורות גיאומטריות (OOP)

מערכת מבוססת Python המחשבת שטח והיקף של צורות גיאומטריות שונות תוך שימוש בעקרונות תכנות מונחה עצמים (OOP).

## צורות נתמכות במערכת:
* מלבן (`Rectangle`)
* ריבוע (`Square`)
* משולש (`Triangle`)
* מעגל (`Circle`)
* משושה משוכלל (`Hexagon`)

## פיצ'רים מרכזיים:
* **ארכיטקטורת OOP מלאה:** שימוש מתקדם בירושה, פולימורפיזם ומתודות קסם (`__str__`).
* **מנגנון הגנה דינמי:** מחלקת הבסיס `Shape` מחזיקה בדיקה אוטומטית המונעת הזנת ערכים שליליים, אפס או קלטים שאינם מספרים.
