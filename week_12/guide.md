המדריך הזה נכתב בדיוק במבנה המפורט, הברור והמובן שלמדנו יחד, ומבוסס 100% על קובץ ה-`data.js` שלך ועל שיטות ההוראה של המורים שלך (ללא המצאות וללא קודים מוכנים מאפס).

כל פרק מחולק ל-3 חלקים:

2. **🛠️ מה אנחנו רוצים לעשות בקובץ הזה?** (המטרה שלנו בפרויקט).
3. **📋 שלבי העבודה המפורטים** (מה לכתוב שורה אחרי שורה, שלב אחר שלב).

## 📞 פרק 1: קובץ `callbacks.js` (כבר עשינו יחד!)

### 💡 על המנגנון: Callback ושיטת Error-First
פונקציה אסינכרונית (כמו כזו שיש בה טיימר `setTimeout`) לא יכולה להחזיר תשובה מיידית עם `return`. 
לכן, אנחנו מעבירים לה כפרמטר פונקציה נוספת (קולבק), והיא תפעיל אותה כשהפעולה תסתיים.
בשיטת **Error-First**, הפרמטר הראשון של הקולבק הוא תמיד שגיאה (או `null` אם הכל תקין), והפרמטר השני הוא המידע שמצאנו.

### 🛠️ מה אנחנו רוצים לעשות בקובץ הזה?
אנחנו רוצים לכתוב פונקציה (שנקראת `getStudentByCallback`) שמקבלת `id` של סטודנט, מחפשת אותו במערך הסטודנטים מתוך `data.js`, ומחזירה את התוצאה דרך Callback אחרי השהייה של שנייה.

### 📋 שלבי העבודה בקובץ:
1. **ייבוא:** מייבאים את מערך הסטודנטים (`students`) מתוך `./data.js`.
2. **יצירת הפונקציה:** יוצרים פונקציה שמקבלת 2 פרמטרים: `id` (התעודת זהות של הסטודנט) ו-`callback` (הפונקציה שתרוץ בסוף).
3. **הלוגיקה בפנים:**
   * מפעילים `setTimeout` של 1000 מילישניות (שנייה אחת).
   * בתוך הטיימר, מחפשים את הסטודנט במערך בעזרת פונקציית `.find()`.
   * **אם הסטודנט נמצא:** קוראים ל-`callback(null, student)` (פרמטר ראשון ריק משגיאות, פרמטר שני הסטודנט).
   * **אם הסטודנט לא נמצא:** קוראים ל-`callback("Student not found")` (מעבירים מחרוזת שגיאה בפרמטר הראשון).
4. **ייצוא:** מייצאים את הפונקציה החוצה עם `export`.

## 🤝 פרק 2: קובץ `promises.js` (כבר עשינו יחד!)

### 💡 על המנגנון: הבטחות (Promises)
במקום להעביר פונקציית callback מסורבלת, פונקציה יכולה להחזיר אובייקט מסוג `Promise` (הבטחה). מי שיקרא לפונקציה הזו יוכל לשרשר אליה `.then()` כדי לטפל בהצלחה, ו-`.catch()` כדי לטפל בשגיאה.

### 🛠️ מה אנחנו רוצים לעשות בקובץ הזה?
אנחנו רוצים לכתוב פונקציה (שנקראת `getTaskById`) שמקבלת `id` של משימת לימוד, מחפשת אותה במערך המשימות, ומחזירה הבטחה לעתיד.
**הערה חשובה להמשך:** כדי שנוכל לחפש סטודנט בצורה חלקה בשלב הבא עם `await`, מומלץ מאוד ליצור באותו קובץ בדיוק פונקציה נוספת (למשל `getStudentById`) שעושה את אותו דבר בדיוק עבור סטודנטים!

### 📋 שלבי העבודה בקובץ:
1. **ייבוא:** לייבא את מערך המשימות (`studyTasks`) ואת מערך הסטודנטים (`students`) מתוך `./data.js`.
2. **יצירת הפונקציה:** ליצור פונקציה `getTaskById` שמקבלת פרמטר אחד בלבד: `id`.
3. **החזרת ה-Promise:** בתוך הפונקציה, להחזיר אובייקט Promise חדש: `return new Promise((resolve, reject) => { ... });`.
4. **הלוגיקה בפנים:**
   * בתוך ה-Promise, מפעילים `setTimeout` של 1000 מילישניות.
   * מחפשים את המשימה במערך ה-`studyTasks` בעזרת `.find()`.
   * **אם המשימה נמצאה:** קוראים ל-`resolve(task)` (מעביר את המשימה להצלחה).
   * **אם המשימה לא נמצאה:** קוראים ל-`reject("Task not found")` (מעביר שגיאה לכישלון).
5. **פונקציה שנייה (עבור הסטודנטים):** צור פונקציה נוספת באותו קובץ בשם `getStudentById`, שעושה בדיוק את אותם שלבים, אבל מחפשת בתוך מערך ה-`students`, ואם לא מוצאת עושה `reject("Student not found")`.
6. **ייצוא:** לייצא את שתי הפונקציות החוצה.

## ⚡ פרק 3: קובץ `asyncAwait.js` (השלב הבא שלך!)

### 💡 על המנגנון: Async / Await ו-Try / Catch
זהו "שדרוג תחבירי" (Syntactic Sugar) מעל Promises. במקום לכתוב שרשראות של `.then()`, אנחנו כותבים את הקוד כאילו הוא קוד רגיל שרץ שורה אחרי שורה.
* **הכלל הכי חשוב של `await`:** מותר לשים `await` **אך ורק לפני פונקציה שמחזירה Promise**! הוא ממתין בסבלנות שה-Promise יסתיים (יעשה resolve), ומחזיר את התוצאה שלו ישירות למשתנה.
* **איך תופסים שגיאות?** מכיוון שאין לנו כאן `.catch()`, אנחנו עוטפים את הקוד בבלוק של `try { ... } catch (error) { ... }`. אם ה-Promise נכשל (עשה reject), הקוד קופץ מיד לתוך ה-`catch`.

### 🛠️ מה אנחנו רוצים לעשות בקובץ הזה?
אנחנו רוצים לכתוב פונקציה (נקרא לה `prepareReminder`) שמקבלת `studentId`, מביאה את הסטודנט המלא בעזרת `await`, בודקת אם יש לו פרטי קשר (לפי `.contactInfo` כמו שבחרת או `.hasReminderContact`), ומחזירה הודעת תזכורת מתאימה.

### 📋 שלבי העבודה בקובץ (שלב אחר שלב):
1. **ייבוא:** ייבא את פונקציית החיפוש שמחזירה Promise מתוך `./promises.js` (את `getStudentById` שיצרנו בשלב הקודם).
   *(שים לב: אל תיבא את `getStudentByCallback`, כי `await` לא יודע לעבוד עם Callback רגיל!).*
2. **יצירת הפונקציה:** כתוב פונקציה בשם `prepareReminder(studentId)`. חובה להוסיף את המילה `async` לפני המילה `function`!
3. **עטיפה ב-Try / Catch:** פתח בלוק `try { ... }` ואחריו בלוק `catch (error) { ... }`.
4. **הלוגיקה בתוך ה-`try`:**
   * צור משתנה והמתן לתשובה מהפרומיס: `const student = await getStudentById(studentId);`.
   * עכשיו, כשיש לך את הסטודנט ביד, עשה בדיקת `if / else` רגילה לגמרי:
   * **אם אין לו פרטי קשר** (כלומר `if (!student.contactInfo)` או `if (!student.hasReminderContact)`): תחזיר (`return`) הודעה כמו `"Cannot prepare reminder: Missing contact info"`.
   * **אם יש לו פרטי קשר:** תחזיר (`return`) הודעת תזכורת מוכנה עם השם שלו, למשל: `"Reminder for " + student.name + ": Time to study!"`.
5. **הלוגיקה בתוך ה-`catch (error)`:**
   * אם שלחנו ID של סטודנט שלא קיים במערך, הפרומיס של החיפוש יכשיל את הפעולה (reject). הקוד יקפוץ ישירות לכאן!
   * בתוך ה-`catch`, החזר (`return`) או הדפס את השגיאה שקיבלת: `"Error: " + error`.
6. **ייצוא:** ייצא את פונקציית `prepareReminder`.

## 💾 פרק 4 (בונוס מומלץ): קובץ `storage.js`

### 💡 על המנגנון: עטיפת מודול קבצים (fs) בפרומיס
בתרגילי הבית שלכם למדתם איך לקחת פונקציה שעובדת עם Callback (כמו `fs.writeFile` או `fs.readFile` מהמודול הרגיל של Node.js), ולהפוך אותה לפרומיס על ידי עטיפתה ב-`new Promise((resolve, reject) => { ... })`.

### 🛠️ מה אנחנו רוצים לעשות בקובץ הזה?
אנחנו רוצים ליצור שתי פונקציות:
1. `savePlan(plan)`: שומרת אובייקט של תוכנית לימודים לתוך קובץ טקסט בשם `saved-plan.json`.
2. `loadPlan()`: קוראת את הקובץ `saved-plan.json` והופכת אותו בחזרה לאובייקט בזיכרון.

### 📋 שלבי העבודה בקובץ (שלב אחר שלב):
1. **ייבוא מודול הקבצים:** ייבא את מודול קבצי הליבה של Node: `import fs from "fs";`.
2. **כתיבת פונקציית השמירה (`savePlan`):**
   * הפונקציה מקבלת פרמטר אחד: `plan` (אובייקט תוכנית הלימודים).
   * בתוכה, החזר פרומיס חדש: `return new Promise((resolve, reject) => { ... });`.
   * הפוך את אובייקט ה-`plan` למחרוזת טקסט: `const data = JSON.stringify(plan);`.
   * קרא לפונקציה של Node לכתיבת קובץ: `fs.writeFile("./saved-plan.json", data, "utf-8", (err) => { ... })`.
   * בתוך הקולבק של הכתיבה: אם יש שגיאה (`if (err)`), קרא ל-`reject(err)`. אם הכל תקין, קרא ל-`resolve("Plan saved successfully!")`.
3. **כתיבת פונקציית הקריאה (`loadPlan`):**
   * הפונקציה לא מקבלת פרמטרים.
   * בתוכה, החזר פרומיס חדש: `return new Promise((resolve, reject) => { ... });`.
   * קרא לפונקציה של Node לקריאת קובץ: `fs.readFile("./saved-plan.json", "utf-8", (err, data) => { ... })`.
   * בתוך הקולבק של הקריאה: אם יש שגיאה (`if (err)`), קרא ל-`reject(err)`.
   * אם הכל תקין, הפוך את מחרוזת ה-`data` בחזרה לאובייקט בעזרת `JSON.parse(data)`, והעבר אותו להצלחה: `resolve(JSON.parse(data))`.
4. **ייצוא:** ייצא את שתי הפונקציות החוצה.

## 🎮 פרק 5: הקובץ הראשי שמריץ הכל (`main.js`)

### 💡 על המנגנון: חיבור כל החלקים לפלט אחד
קובץ `main.js` הוא "מנהל העבודה" של האפליקציה. אותו אנחנו מריצים בטרמינל עם הפקודה `npm start`. הוא קורא לפונקציות שבנינו בכל הפרקים ומדפיס למשתמש את התוצאות, כדי להוכיח שכל הלוגיקה האסינכרונית עובדת.

### 🛠️ מה אנחנו רוצים לעשות בקובץ הזה?
אנחנו רוצים ליצור רצף בדיקות ומשימות שמציג את כל הפלט הנדרש במסמך ההנחיות של הפרויקט: תלמיד שנמצא, תלמיד שלא נמצא, משימות, תזכורות, ושמירה לקובץ.

### 📋 שלבי העבודה בקובץ (שלב אחר שלב):
1. **ייבוא מכל הקבצים:**
   * ייבא את `getStudentByCallback` מתוך `./callbacks.js`.
   * ייבא את `getTaskById` מתוך `./promises.js`.
   * ייבא את `prepareReminder` מתוך `./asyncAwait.js`.
   * *(אם עשית את הבונוס)* ייבא את `savePlan` ו-`loadPlan` מתוך `./storage.js`.

2. **שלב א': הדפסת פתיחה והוכחת אי-חסימה (Non-Blocking):**
   * הדפס הודעה שהאפליקציה התחילה לרוץ: `console.log("--- Study Planner Started ---");`.
   * קרא לפונקציית ה-Callback עבור סטודנט שקיים (למשל ID 1):
     `getStudentByCallback(1, (err, student) => { if (err) console.log(err); else console.log("Found Student (Callback):", student.name); });`
   * **מיד בשורה שאחרי** (מחוץ לקולבק!), הדפס הודעה רגילה: `console.log("Searching for student... (this prints BEFORE the callback finishes!)");`.
   * *הוכחה:* כשתריץ, תראה שההדפסה השנייה מופיעה על המסך **לפני** התשובה מהקולבק!

3. **שלב ב': בדיקת שגיאה בקולבק (תלמיד שלא קיים):**
   * קרא ל-`getStudentByCallback` עם ID שגוי (למשל 99).
   * בתוך הקולבק, בדוק: אם יש שגיאה (`if (err)`), הדפס אותה למסך: `console.log("Error from Callback:", err);`.

4. **שלב ג': שרשור Promises (הבאת משימות לימוד):**
   * קרא ל-`getTaskById(101)` ושרשר אליו `.then()` שמקבל את המשימה ומדפיס: `console.log("Task 101:", task.title);`.
   * מתוך ה-`.then()` הזה, החזר קריאה נוספת ל-`getTaskById(102)` (כדי ליצור שרשרת!).
   * שרשר `.then()` שני שמקבל את המשימה השנייה ומדפיס אותה.
   * שרשר `.catch()` שמדפיס שגיאות אם משימה לא נמצאה.
   * שרשר `.finally()` שמדפיס: `console.log("Finished task search.");`.

5. **שלב ד': הפעלת Async / Await (הכנת תזכורות):**
   * מכיוון ש-`prepareReminder` היא פונקציה אסינכרונית שמחזירה Promise, אנחנו יכולים לקרוא לה ולטפל בה עם `.then()`, או ליצור בתוך `main.js` פונקציה אסינכרונית מריצה (למשל `async function runReminders()`) ולקרוא לה.
   * הפעל את `prepareReminder(1)` (סטודנט עם פרטי קשר) והדפס את התשובה שחזרה.
   * הפעל את `prepareReminder(2)` (סטודנט בלי פרטי קשר) והדפס את התשובה שחזרה (תראה שמתקבלת ההודעה שחסרים פרטי קשר).
   * הפעל את `prepareReminder(99)` (סטודנט שלא קיים) ותראה איך הודעת השגיאה מודפסת בצורה מסודרת.
