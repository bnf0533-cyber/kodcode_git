# **מערכת CRUD לחיילים**

עליכם לבנות שרת **Express** שמתחבר ל־DB ומנהל מידע על חיילים.

הפרויקט צריך לכלול **CRUD מלא**:  
 יצירה, שליפה, עדכון ומחיקה של חיילים.

## **מה צריך להיות בפרויקט**

שרת Express שמחובר ל־DB כלשהו לבחירתכם.

המערכת צריכה לנהל חיילים, כאשר לכל חייל יש פרטים בסיסיים כמו:  
 שם, תפקיד, דרגה, יחידה, גיל, מצב שירות, ותאריך יצירה.

## **פעולות חובה**

### **יצירת חייל חדש**

POST /soldiers

השרת יקבל נתונים ב־Body, ישמור חייל חדש ב־DB, ויחזיר את החייל שנוצר.

### **קבלת כל החיילים**

GET /soldiers

השרת יחזיר את כל החיילים מה־DB.

צריך לאפשר סינון בעזרת Query Params, לדוגמה:

GET /soldiers?unit=8200  
GET /soldiers?rank=Sergeant  
GET /soldiers?status=active  
GET /soldiers?unit=8200\&status=active

### **קבלת חייל לפי מזהה**

GET /soldiers/:id

השרת יקבל מזהה דרך Params, יחפש את החייל ב־DB, ויחזיר אותו.

אם החייל לא נמצא, יש להחזיר שגיאה מתאימה.

### **עדכון חייל**

PUT /soldiers/:id

השרת יקבל מזהה דרך Params ונתונים חדשים דרך Body, יעדכן את החייל ב־DB, ויחזיר את החייל המעודכן.

### **מחיקת חייל**

DELETE /soldiers/:id

השרת יקבל מזהה דרך Params, ימחק את החייל מה־DB, ויחזיר הודעת הצלחה.

### **שינוי סטטוס שירות**

PATCH /soldiers/:id/status

השרת יקבל מזהה דרך Params וסטטוס חדש דרך Body, יעדכן רק את סטטוס השירות של החייל, ויחזיר את החייל המעודכן.

## **ארכיטקטורה נדרשת**

הפרויקט צריך להיות בנוי בצורה מסודרת לפי שכבות שנראות לך נכונות.

## **דרישות חובה**

הפרויקט חייב לכלול:

* Express server  
* חיבור ל־DB  
* CRUD מלא  
* שימוש ב־Body  
* שימוש ב־Params  
* שימוש ב־Query Params  
* הפרדה נכונה בין תיקיות וקבצים  
* טיפול בשגיאות  
* החזרת תשובות JSON  
* Status codes תקינים

## **טיפול בשגיאות**

יש לטפל לפחות במקרים הבאים:

* חסרים נתונים חובה  
* מזהה לא קיים  
* ערכים לא תקינים  
* שגיאת DB  
* שגיאת שרת כללית

## **Status Codes נדרשים**

200 \- פעולה הצליחה  
201 \- יצירה הצליחה  
400 \- בקשה לא תקינה  
404 \- חייל לא נמצא  
500 \- שגיאת שרת

## **בדיקות חובה**

יש לבדוק את כל ה־Endpoints בעזרת Postman:

* יצירת חייל  
* קבלת כל החיילים  
* סינון חיילים לפי Query Params  
* קבלת חייל לפי ID  
* עדכון חייל  
* שינוי סטטוס בלבד  
* מחיקת חייל  
* ניסיון לשלוף חייל שלא קיים  
* ניסיון לשלוח נתונים חסרים  
* ניסיון לשלוח ערכים לא תקינים
