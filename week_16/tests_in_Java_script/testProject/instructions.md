# פרויקט: מחשבון חנות — `store-calc`

## הסיפור

אתם בונים את מנוע התמחור של חנות אונליין קטנה.
המנהלת ביקשה בקשה אחת: **לפני שמעלים לייצור — כל חישוב חייב להיות מכוסה בבדיקות.**

המשמעות: כל פונקציה שכתבתם → בדיקה שמוכיחה שהיא עובדת נכון.

---

## מבנה הפרויקט

```
store-calc/
  package.json        ← צרו עם "type": "module"
  store-calc.js       ← הפונקציות שתכתבו
  store-calc.test.js  ← הבדיקות שתכתבו
```

---

## הפונקציות לממש

### 1. `calculateDiscount(price, percent)`
מחשבת מחיר לאחר הנחה באחוזים.
- מקבלת: מחיר (מספר), אחוז הנחה (0–100)
- מחזירה: המחיר לאחר הנחה
- דוגמה: הנחה של 20% על מחיר 100 → 80; הנחה של 0% → המחיר לא משתנה

### 2. `applyTax(price, taxRate)`
מוסיפה מע"מ למחיר.
- מקבלת: מחיר (מספר), שיעור מס (0.17 = 17%)
- מחזירה: המחיר כולל המס
- דוגמה: מחיר 100 עם מע"מ 17% → 117; מחיר 0 → נשאר 0

### 3. `calculateCartTotal(items)`
מחשבת את הסכום הכולל של עגלת קניות.
- מקבלת: מערך של פריטים, כל פריט הוא `{ price, quantity }`
- מחזירה: הסכום הכולל (price × quantity לכל פריט, ביחד)
- מקרה קצה: עגלה ריקה → מחזירה 0

### 4. `validatePrice(price)`
בודקת שמחיר הוא ערך תקין — **זורקת שגיאה** אם לא.
- קלט שאינו מספר → שגיאה עם הודעה ברורה
- מחיר שלילי → שגיאה עם הודעה ברורה
- מחיר אפס → תקין (מוצר חינמי)
- מחיר חיובי → לא זורקת שגיאה

### 5. `formatPrice(amount)`
מעצבת מחיר לתצוגה עם סימן שקל ו-2 ספרות עשרוניות.
- מקבלת: מספר
- מחזירה: מחרוזת בפורמט `₪XX.XX`
- דוגמה: 49.9 → `₪49.90`; 100 → `₪100.00`

## הנחיות כתיבה

**קובץ הלוגיקה (`store-calc.js`):**
- ייצאו כל פונקציה עם `export`
- כל פונקציה עצמאית — ללא תלות חיצונית

**קובץ הבדיקות (`store-calc.test.js`):**
- ייבאו את node:test ואת node:assert בתחילת הקובץ (`import`)
- ייבאו את הפונקציות מ-`store-calc.js` (`import`)
- ארגנו כל קבוצת בדיקות בתוך `describe` עם שם ברור
- לפחות 3 בדיקות לכל פונקציה

**package.json:**
- הוסיפו `"type": "module"` כדי להפעיל ES modules בפרויקט

## הרצה

```bash
node --test store-calc.test.js
```

בדיקות שעוברות → ✔. בדיקות שנכשלות → ✖ עם תיאור מה ציפיתם לקבל לעומת מה קיבלתם.

## שלבים מומלצים

### שלב 1 — TDD על פונקציה אחת
בחרו את `calculateDiscount`. כתבו **קודם את הבדיקות** — הריצו ← כל הבדיקות אדומות. ממשו את הפונקציה ← הכל ירוק.

### שלב 2 — ממשו את שאר הפונקציות
עבדו פונקציה אחת בכל פעם: בדיקה → מימוש → ריצה.

### שלב 3 — מקרי קצה
לכל פונקציה חשבו: מה קורה עם `0`? עם `null`? עם מספר שלילי? הוסיפו בדיקות.

### שלב 4 — שברו בכוונה
שנו שורה אחת בפונקציה שהכי בדקתם → הריצו → ראו כמה בדיקות נפלו ומה הפלט אומר.
